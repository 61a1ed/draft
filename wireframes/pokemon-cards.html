Wireframes: Pokémon catalog card & detail pop-out

Low-fidelity layout only. Type colors are final; other colors, icons, and styling are not decided here. Sample data is real data from pokemon_details.json (the saved Showdown snapshot), and sprites load from showdown/sprites.

1 numbered notes explain layout decisions Dashed box = placeholder / existing feature

1. Catalog card

Shows the sprite, point value, name, type(s), Mega Evolutions, and a favorite button. Click a card to open its pop-out; the favorite button works on its own without opening it.

1 Sprite at the top, with the favorite / add to list button in its top-left corner (★ = saved to the selected favorites list, ☆ = not saved). Top-left keeps it diagonally opposite the points ribbon, so the two never crowd each other. It is a separate button, so saving never opens the pop-out.

2 Name is the species; a non-base form (Alolan, Female, …) sits on a second line so cards stay the same width.

3 Types as colored pills, in Showdown order (primary first). Text is dark or white, whichever is easier to read on that type's color.

4 Mega Evolutions list each Mega by name with its own types, since Megas can change type (e.g. Mega Charizard X becomes Fire/Dragon). Pokémon without a Mega show "No Mega Evolution" so every card has the same structure.

5 Point value on a ribbon in the sprite's bottom-right corner. It wraps past the card edge with a folded tail, so it reads as "attached" to the card rather than floating on the art.

2. Detail pop-out (opened from a card)

Static copy of the pop-out for review; the live version opens over the page when you click a card.

Sprite carries the same points ribbon as the card, so the cost looks the same in both places. A Mega costs the same as its base Pokémon, so the ribbon stays put on every tab.

6 Form tabs: the base form first, then one tab per Mega. Switching tabs swaps the sprite, types, abilities, and stats in place, so Megas use the same layout. Tabs are hidden when there is no Mega. Megas without a sprite yet (e.g. Mega Meowstic) show a placeholder.

7 Abilities: one plain list. Hidden abilities are not marked, since Champions treats them like any other ability. Megas have exactly one ability.

8 Base stats: six bars on a shared 0–255 scale, plus the total. On a Mega tab, the small blue number shows the change from the base form (e.g. +46 Attack).

9 Footer repeats the points next to the draft action, where the decision is made. The favorite button here mirrors the card's, so it stays in sync.
